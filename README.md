# inforprimetecnologiadev.github.io

Raiz do domínio do GitHub Pages da Inforprime.

`.well-known/assetlinks.json` prova ao Android que os apps abaixo pertencem a este site.
Sem ele, o app abre com a barra de endereço do navegador em cima.

| App | Pacote | Site |
|---|---|---|
| Não Esquece | `com.inforprime.naoesquece` | https://inforprimetecnologiadev.github.io/nao-esquece/ |

`.nojekyll` faz o GitHub Pages publicar a pasta `.well-known` (o Jekyll ignora pastas que começam com ponto).
